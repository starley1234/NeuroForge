## Почему TTT даёт O(1)

KV-кэш хранит `2 · N · H_kv · d_head · L` чисел — линейно по длине контекста.
Быстрые веса хранят `H · d_v · d_k` на слой — **константа**. Проверка:

```bash
nexus needle --lengths 1024,8192,32768
```

`state_mb` не меняется, `kv_cache_mb_if_full_attention` растёт линейно,
`compression_x` — во сколько раз выиграли. Метрика `recall_cosine` показывает,
насколько точно «игла» извлекается из быстрых весов запросом её ключа: на
необученных весах это 0.45–0.64 при контексте 1k…64k — за счёт гейтинга по
дельте новизны шум почти не перезаписывает память.

Внутри чанка используется классическая chunk-wise аппроксимация
`M_{t-1} ≈ M_0` в члене ошибки; при `chunk_size = 1` правило дельты точное,
и тест `test_ttt_chunking_equivalent_to_streaming` подтверждает совпадение
чанкового прохода с потоковым по одному токену.

## Непрерывное время против индекса токена

`ContinuousTimeEmbedding` кодирует t в секундах логарифмической сеткой периодов
от 0.1 мс до 10 000 с. `GatedDeltaSSM` интегрирует состояние с шагом
`exp(A·Δt)`, то есть пауза 400 мс между вспышкой и звуком физически меняет
состояние ровно так же, сколько бы токенов в неё ни попало. Шина сортирует
разномодальные пакеты по общему времени — причинность сохраняется.

## Физические инварианты

`LatentPacket` несёт `position` (м), `time` (с), `mass` (кг), `force` (Н).
Шина проецирует их линейным слоем и складывает с признаками, так что «где»,
«когда», «сколько весит» и «какая сила» — часть каждого токена, а не догадка
по 2D-проекции.

## Геометрический аудит

| Проверка | Метод |
| :-- | :-- |
| manifold | одна 6-связная компонента материала и деталь не упирается в границу домена |
| внутренние полости | компоненты пустоты, не связанные с внешней границей |
| толщина стенки | 2-й перцентиль длин сплошных отрезков по каждой оси × шаг вокселя |
| свесы для печати | доля вокселей без опоры снизу |
| ЧПУ 3-осевой | доля вокселей, видимых лучом сверху |

Сетка **анизотропная**: шаг свой по каждой оси. Иначе плита 120 × 80 × 2 мм
на кубической сетке 24³ просто исчезает — типовая ошибка воксельных пайплайнов.

## Награды Physics-RL

```
+1.0  CSG собрался (код компилируется)
+1.5  manifold и проходит аудит печати/фрезеровки (+0.5 если manifold, но есть замечания)
+2.0  запас прочности ≥ требуемого (частично, если ≥ 1.0; −1.0, если деталь не держит)
−     штраф за перевес и за тонкие стенки/большие свесы
```

GRPO: K сэмплов на промпт, baseline — среднее по группе, KL к референсной
политике. Обучаемого критика нет — «критик» это физика.
