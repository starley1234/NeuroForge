# Hyperion — гибридная мультимодальная LLM архитектура

> Реализация архитектуры, описанной в [`HYPERION_ARCHITECTURE.md`](HYPERION_ARCHITECTURE.md).

Hyperion — экспериментальный исследовательский проект: сборка ключевых архитектурных инноваций 2024–2026 в одну вычислительно эффективную мультимодальную LLM. Цель — работа на ограниченных ресурсах при качестве, не уступающем моделям в 2× больше.

## Компоненты

| Модуль | Файл | Что делает |
|---|---|---|
| **MLA** — Multi-Head Latent Attention | `hyperion/core/mla.py` | Сжимает KV-кэш в латентное пространство (~16×), качество ≥ MHA (DeepSeek-V2/V3) |
| **Mamba-3** — State Space Model | `hyperion/core/mamba3.py` | Линейная сложность O(n) по длине контекста, вход-зависимая селективность, каузальная свёртка |
| **Titans Memory** — нейронная память | `hyperion/core/titans_memory.py` | Трёхветвевая память: рабочая (окно внимания) + нейронная (test-time learning) + persistent; surprise-gated запись |
| **MoSE** — Slimmable MoE | `hyperion/core/mose.py` | Эксперты с вложенными ширинами: один прогон модели даёт спектр точность/compute |
| **JEPA** — Joint Embedding Predictive | `hyperion/core/jepa.py` | Обучение предсказанием эмбеддингов будущих токенов (не токенов) |
| **MTP** — Multi-Token Prediction | `hyperion/core/mtp.py` | Плотный градиентный сигнал + спекулятивное декодирование (DeepSeek-V3) |
| **Сборка** | `hyperion/model.py` | Гибридный backbone: чередование SSM / MLA / Memory + MoSE, JEPA+MTP цели |

## Запуск

```bash
pip install -r requirements.txt        # torch, einops, numpy
python tests/test_components.py        # юнит-тесты компонентов (~5 сек)
python tests/test_integration.py       # интеграционный тест модели (~10 сек)
python demo.py                         # полная демонстрация (~3 мин, CPU)
```

## Ключевые решения реализации

- **Стабильность памяти**: ключи/значения нормируются к единичной норме, матрица `M` спектрально ограничена — нет расходимости (в наивной версии `||M||` рос экспоненциально).
- **Правильный градиент записи**: `∂L/∂M = kᵀ(k·M − v)` (транспонированный вариант не сходится).
- **Остаточное чтение памяти**: `v̂ = M·k + mlp(M·k)` — необученный MLP не может заглушить ассоциативную выборку.
- **Нормированная ветка памяти**: ветка (core+persistent+neural) нормализуется перед добавлением к residual — иначе сигнал памяти тонет в residual-потоке и модель его игнорирует (обучение улучшилось с 0.82 → 0.09 на toy-задаче).
- **Ассоциация «ключ → следующий»**: память хранит пары `(k_t, v_{t+1})`, что прямо помогает next-token prediction.
- **Малые веса вспомогательных целей**: JEPA и MTP с весом 0.05 — при 0.1+ они забивают основную цель.

## Ограничения

- Игрушечная задача в `demo.py` — проверка работоспособности стека, не бенчмарк.
- Mamba-3 реализован упрощённо (последовательный скан, exp-Euler дискретизация) без кастомных CUDA-ядер; для продакшена использовать официальные ядра (causal-conv1d, mamba-ssm).
- Требуется PyTorch ≥ 2.1.
